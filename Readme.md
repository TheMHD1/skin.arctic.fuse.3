## Personal Jellyfin integration fork

This branch contains our Arctic/Jellyfin/KodiSeerr integration, trailer actions,
regression checks and upgrade instructions. Start with [integration/README.md](integration/README.md)
and [the update guide](integration/UPDATING.md). Arctic Fuse is by jurialmunkey;
this is an unofficial, non-commercial source integration branch, not an automatic-update repository.
Private accounts, settings and backups are not included.
