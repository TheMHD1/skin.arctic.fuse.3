# Home freshness and separated library search

This directory is the portable, exact-cohort update for the September 22 Home
ordering/freshness and owned-versus-Venom search separation. It is not a blank
device installer and does not modify Jellyfin credentials, Home scope settings,
Kodi databases, server configuration or CoreELEC.

The guarded transaction replaces six maintained sources, the generated Arctic
search include, and its GUID-bearing Skin Variables node cache, then updates the
existing integrity manifest. Generated bytes are derived only from the exact
reviewed r6 files, so source templates, cache and active include change atomically
in one Kodi stop/start. The
separate `rebuild.py` is retained for a future reviewed template rebuild; it is
not needed by this exact installer and must only run while idle.

Local deployment passed on September 23: all nine paths were updated, Kodi
restarted, authenticated server access resumed, and a second no-write plan
reported zero changes. Installed-source/API checks verified watch-activity
ordering and server-backed Home rows. The remote cohort is not deployed;
no firmware update or Dolby Vision policy change was part of this transaction.

Build from a committed clean fork:

```sh
python3 integration/release/library-experience/build.py --output /tmp/library-payload
```

Copy this directory and the sibling `kodi/` directory while preserving their
`release/library-experience` and `release/kodi` layout, plus the payload and a
private profile patterned on `../kodi/profile.example.json`, to the target.
First run a no-write plan from `library-experience/`:

```sh
python3 install.py --profile /private/device.json --payload /private/library-payload
```

Apply only after reviewing the nine planned paths and the retained backup:

```sh
python3 install.py --profile /private/device.json --payload /private/library-payload --apply
```

The default refuses active or paused playback. `--allow-active-playback` is an
explicit destructive-session override: it stops Kodi and interrupts playback;
use it only with current user authorization. It does not relax source, manifest,
version, hostname, MAC or Jellyfin-user checks.

The installer accepts only the captured local r6 whole-file cohort or its own
complete output cohort. Partial updates, stale manifests and unrelated source
drift fail before Kodi is stopped. Writes are backed up and use the shared
transaction rollback/readiness behavior. Power loss or forced process death is
not guaranteed rollback; recover manually from the printed backup directory.

Offline tests:

```sh
python3 integration/release/library-experience/test_installer.py
```

Passing source tests are not device acceptance. After deployment, verify Home
ordering/refresh and the five visible sections: Movies, Shows, Venom Movies —
Not HD, Venom Shows — Not HD, and the existing independent Discover section.
